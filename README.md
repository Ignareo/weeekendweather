# 天气批量导出工具

从中国气象台（nmc.cn）批量查询指定城市的**未来 7 天天气预报**，支持筛选汇总（如"周末非雨天、气温 30°C 以下的城市"），有**网页版**和**命令行版**两种用法。

数据来源为国家气象中心未公开接口，**仅供个人学习使用**。

## 网页版（index.html）

零构建单文件网页，浏览器直接完成"抓预报 → 筛选 → 决策汇总"全流程，筛选逻辑与 CLI 版完全一致。

**部署/预览**

```bash
# 本地预览 (fetch 静态资源需要 http 服务, 双击打开 html 不可用)
python3 -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000/index.html
```

部署到 GitHub Pages：仓库 Settings → Pages → 选分支根目录即可，`index.html`、`stations.json`、`holidays.json`、`data.json` 都在根目录直接可访问。

**功能入口**

- 打开页面即自动抓取选中城市的 7 天预报，输出"每城市一行"汇总表（达标天数、逐日雨况、综合雨况、温度区间、总降水、发布时刻），排序与 CLI 一致
- **筛选条件**：日期范围、雨天接受度四档、白天温度上限、夜间温度下限、至少几天达标、出行小时圈；改动即时重算，不重新请求
- **快捷日期**：本周末 / 下周末（`holidays.json` 法定节假日数据保留，按钮暂不显示）；周四/周五打开默认选中本周末
- **城市管理**：展开"城市管理"面板，按省分组勾选、搜索过滤、全选、恢复默认；支持导出/导入文本（每行一城市，与 `cities.txt` 互通）；选中列表存浏览器 localStorage
- **城市行展开**：点击城市名查看体感温度、湿度、AQI、日出日落、风向风力、气象预警详情
- **出行数据**：展开"出行数据"面板，为每城市录入高铁/飞机/自驾时长（自动保存，可导出/导入 JSON），配合"出行小时圈"筛选使用
- **预警徽标**：有气象预警的城市行显示蓝/黄/橙/红分级徽标，点击展开详情并链接 NMC 原文
- **变更对比**：每次抓取自动存快照，下次打开时顶部列出与上次的差异（雨况变坏置顶、温度变化 ≥3°C、变好折叠），汇总表对应格子红/绿高亮；基准超 24 小时会标注时间，可一键清除
- **分享**：「复制分享链接」把城市和全部筛选条件编码进 URL，打开链接即还原视图并自动抓取；「复制文本汇总」生成与 CLI 同格式的纯文本表格
- **温度走势**：底部图表勾选当前筛选结果中的城市，叠加显示今天起 7 天预报高/低温（Chart.js 走 CDN，加载失败不影响其他功能）
- **兜底快照**：直连 nmc.cn 失败的城市自动回退读取 `data.json`（Actions 每天 07/13/19 点生成），并标注"数据快照"；站点代码失效的城市行标红并提示本地运行 `python3 nmc_weather.py refresh`

## 命令行版

从中国气象台（nmc.cn）批量抓取指定城市的**未来 7 天天气预报**，导出为 CSV（Excel 可直接打开），并支持交互式筛选。

## 文件说明

| 文件 | 作用 | 是否需要维护 |
|------|------|------------|
| `nmc_weather.py` | 抓取脚本：按城市列表抓预报，导出 CSV / 网页兜底快照 | 否 |
| `filter_weather.py` | 筛选向导：对结果 CSV 做交互式条件筛选 | 否 |
| `index.html` | 网页版：单文件 SPA，浏览器内完成抓取+筛选+汇总+图表 | 否 |
| `holidays.json` | 法定节假日数据（网页版"下个法定节假日"按钮用） | **是，每年国务院发布后更新** |
| `data.json` | 网页兜底快照（GitHub Actions 定时生成，无需手工维护） | 否 |
| `cities.txt` | 城市列表，一行一个，支持 `#` 注释 | **是，按需编辑** |
| `stations.json` | 全国站点代码缓存 | 否（脚本生成） |
| `weather_forecast_*.csv` | 输出：7 天预报（带生成时间戳，互不覆盖） | 否 |
| `weather_temp14_*.csv` | 输出：前后 14 天气温（可选） | 否 |

## 快速开始

```bash
# 首次使用安装依赖（仅需 requests）
pip3 install requests

# 编辑 cities.txt，每行一个城市名，例如:
#   上海
#   南京
#   厦门

# 一条命令搞定: 没有当日数据会自动先抓取, 然后进入筛选向导
python3 filter_weather.py
```

## 抓取（nmc_weather.py）

```bash
python3 nmc_weather.py            # 读取 cities.txt, 导出未来 7 天预报 CSV
python3 nmc_weather.py --temp14   # 额外导出 近7天实况 + 未来7天 气温 CSV
python3 nmc_weather.py --json <路径>  # 导出网页版兜底快照 data.json (预报+实况+气温原始数据)
python3 nmc_weather.py refresh    # 重建 stations.json 站点缓存(约 40 秒)
```

`--json` 由 GitHub Actions（`.github/workflows/weather-snapshot.yml`）每天 07:00/13:00/19:00 自动运行并提交 `data.json`，供网页版直连失败时兜底；手工运行可加在抓取 CSV 之外单独执行。

`weather_forecast_*.csv` 列：城市、省份、发布时刻、日期、白天/夜间天气、温度、风向、风力、降水量（mm)。编码为 `utf-8-sig`，Excel 双击打开不乱码。

注意 NMC **没有超过 7 天的预报**：详细天气（风向、降水等）只有未来 7 天；`--temp14` 中的"前 7 天"是实况气温。

## 筛选（filter_weather.py）

```bash
python3 filter_weather.py            # 自动选当日数据(没有则先抓取), 进入向导
python3 filter_weather.py <文件名>   # 手动指定历史 CSV
```

交互式向导，逐项提问筛选条件，**直接回车 = 不限**：

- 日期范围（支持 `8-16`、`8/16`、`08-16` 等写法，自动补全年份）
- **雨天接受度**（四档选一，旅游决策的核心问题）：
  `1` 只接受无雨 / `2` 小雨可以 / `3` 中雨也行 / `4` 不限
- 白天温度上限 / 夜间温度下限
- 只看某个城市
- **至少几天达标**（日期范围 >1 天时出现）：默认全部达标；行程可调时可放宽，如三天输 `2`

**输出为"每城市一行"的行程汇总**，不再逐日罗列：

```
城市    达标    逐日雨况(✗=不达标)    综合雨况      白天温度    夜间温度    总降水
景德镇  2/3     14🌧✗ 15☀️ 16☀️      🌧 中雨      28~33°C   22~25°C   10.0mm
```

- **逐日雨况**：每天一个图标，不达标的日子标 `✗`，三天走势一眼看清
- **综合雨况** = 所选日期内最差的一档（决定行程下限的是最差那天）
- **入选门槛**：达标天数 ≥ 设定值才入选（一天"达标"= 雨况、温度等所有条件都满足）
- **排序**：达标天数多→少，综合雨况好→差，白天最高温低→高

**雨况档位判定**：综合白天天气、夜间天气、降水量（mm）三者，**取较严重者**（昼夜都算）：

| 档位 | 天气文字 | 24h 降水量 | 旅游含义 |
|------|---------|-----------|---------|
| ☀️ 无雨 | 晴/多云/阴 | 0 | 随便玩 |
| 🌦 小雨 | 小雨/阵雨/小雪 | 0.1–9.9 | 带伞即可 |
| 🌧 中雨 | 中雨/雷阵雨/中雪 | 10–24.9 | 户外打折 |
| ⛈ 大到暴雨 | 大雨/暴雨/大暴雨 | ≥25 | 不宜出行 |

天气文字与降水量可能矛盾（如白天"晴"但降水 15mm），取更严重的档位兜底，宁可保守。

非法输入（越界选项、汉字温度、不存在的城市等）会提示后原地重问，不会中断流程。

汇总可导出为 `*_summary.csv`（含逐日明细文字，原文件不动；`_filtered`/`_summary` 文件不会被当作数据源）。

示例：找 8.14–8.16 三天、最多接受到小雨、白天 35°C 以内的目的地——开始 `8-14`，结束 `8-16`，接受度 `2`，白天温度上限 `35`，至少几天达标回车（=3 全达标）或输 `2` 放宽。

## 行为说明

- **重复城市**：自动去重并提醒，只抓取一次
- **城市名找不到**：跳过该城市并提醒，其余城市照常导出；结束时汇总失败列表并以退出码 1 结束
- **抓取失败**（网络问题等）：同样跳过并提醒，不影响其他城市
- 每城市仅 1 次请求，间隔 0.3 秒，30 个城市约 15 秒跑完
- 每次抓取生成带时间戳的新 CSV，互不覆盖；筛选默认用当日文件，当日有多份时取最新一份

## 城市名匹配规则

- 优先精确匹配（如 `南京`）
- 其次前缀匹配（如 `南京` 可匹配 `南京市` 类条目）
- 写的是站点/区县名，县级市、区也可以（如 `昆山`）
- 若大量城市找不到，可能是官方重置了站点代码，运行 `python3 nmc_weather.py refresh` 重建缓存即可

## 数据时效

预报每天约 **06:00 / 12:00 / 18:00** 更新三次，CSV 中的"发布时刻"列标识本次数据的发报时间。同一天内多次抓取只是发布时间不同，可按需保留或删除旧文件。
